# bearweb — Yes Steve Model (YSM) 모델링

이 저장소는 **Yes Steve Model(YSM)용 캐릭터/엔티티 모델** 전용입니다.

> 기존 SevenHope 애드온(무기 모델링, `SevenHope_BP` / `SevenHope_RP`)과는 **완전히 별개**입니다.
> SevenHope 쪽 파일·도구는 이 저장소에 두지 않고, 여기 작업도 SevenHope에 섞지 않습니다.

## YSM 이란
- Minecraft **Java 에디션** 모드 (Forge / NeoForge / Fabric)
- 플레이어 모델을 **Bedrock 형식 geometry + 애니메이션**(Blockbench) 으로 교체
- 모델은 게임의 `config/yes_steve_model/custom/` 에 폴더 형식으로 넣어 사용
  (배포용: 압축 패키지 또는 암호화된 `.ysm`)

## 폴더 구조
```
models/      모델 하나당 폴더 하나 (YSM 폴더 형식 그대로)
reference/   참고 이미지, 컨셉, 레퍼런스 모델
```
