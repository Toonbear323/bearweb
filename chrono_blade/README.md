# 시공의 분침 V1 (vh:chrono_blade)

보스 「시간의 여신」을 쓰러뜨리면 얻는 검. 여신의 브레게 분침 검 실루엣을 잇되, 칼날 자체가 찢어진 시공간.

- `SevenHope_ChronoBlade_V1.mcaddon` — 더블클릭으로 가져오기 (보스 「시간의 여신」 + 소환 아이템 「멈춘 회중시계」 + 검 포함, 따로 설치되는 새 UUID 팩)
- `preview_V1.png` — 미리보기

## 스킬
| 입력 | 이름 | 효과 |
|---|---|---|
| 탭 | 분침 베기 | 앞으로 날아가는 검기 (세 번째마다 엇갈린 두 줄) · 맞은 적에 시차 표식 (최대 3) |
| 꾹 → 놓기 | 시간 압축 → 자정 일섬 | 0.5초마다 한 시각 (최대 12시) · 둘레 적 느려짐 → 바라보는 쪽으로 돌진하며 길 위의 적을 벰 → 0.7초 뒤 시각·표식만큼 터짐 (12시 = 자정 보너스) · 쿨 6초 |
| 웅크리고 | 찢어진 자정 | 발밑에 큰 시계 · 반지름 14칸의 시간이 멈춤 · 일곱 번 가르며 피해를 쌓음 → 내리그으면 한꺼번에 · 쿨 35초 |
| 패시브 | 시차의 잔상 | 근접으로 때린 적을 1.2초 뒤 잔상이 한 번 더 벰 · 들고 있으면 둘레가 밝아짐 |

## 소스 (SevenHope 생성기 묶음에 넣어 씀)
- `source/gen_chrono_blade.py` → `tools/` (모델 · 16칸 플립북 그림 · 애니 · 부착물 · `--icon` 아이콘)
- `source/chrono_blade.js` → `scripts/` (main.js = weapon_main.js + boss_main.js + chrono_blade.js)
- `source/gen_boss_chrono.py` → `tools/` (처치 보상을 `vh:chrono_blade` 로 바꾼 판)
