# 가상 마인크래프트 테스트 도구

화면 없는 **공식 Bedrock 전용 서버(BDS)** 에 내 월드를 올려서 자동으로 검사해 주는 도구입니다.
RPG 월드와 능력 술래잡기 월드를 검증할 때 쓴 방법을 누구나 쓸 수 있게 정리했습니다.

- **월드가 제대로 열리는지**, 행동 팩·리소스 팩이 불러와지는지
- **스크립트·함수·팩 오류**(콘텐츠 로그)가 있는지
- **명령어를 차례로 실행**하고 결과가 맞는지 (시나리오 파일)
- 서버를 1분쯤 **실제로 돌린 뒤 블록이 어떻게 바뀌었는지**: 물·용암이 새는지, 모래가 떨어지는지, 횃불·표지판이 떨어져 나가는지, 몹이 몇 마리 생겼는지
- **콘솔 모드**: 서버를 켜 두고 명령어를 직접 쳐 보거나, 내 마인크래프트로 접속해서 직접 돌아다녀 보기

원본 월드 파일은 절대 바꾸지 않습니다. 서버 폴더에 복사본을 만들어서 그걸로 검사합니다.

---

## 1. 설치 (처음 한 번만)

준비물: **Windows 10/11 (64비트)** 또는 **Linux(우분투 등)**, 인터넷, 빈 공간 약 400MB.
(Bedrock 전용 서버는 Mac용이 없어서 Mac에서는 쓸 수 없습니다.)

### Windows
1. 받은 zip 파일을 **압축 풀기** 합니다 (zip 안에서 바로 실행하지 말고 꼭 풀어 주세요).
2. **`1_install_windows.bat`** 을 더블클릭합니다.
3. 마인크래프트 서버 사용권(EULA) 동의를 물으면 **`y`** 를 입력하고 Enter.
4. "Setup finished" 가 나오면 끝입니다.

설치 파일이 하는 일:
- 이 폴더 안(`runtime\python`)에만 들어가는 **휴대용 파이썬**을 python.org 에서 받습니다 (11MB). PC에 파이썬을 따로 설치하지 않고, 시스템 설정도 바꾸지 않습니다. 받은 파일이 공식 파일이 맞는지 체크섬으로 확인합니다.
- **Bedrock 전용 서버**를 minecraft.net 에서 받아 `server` 폴더에 풉니다 (약 90MB).

> 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
> 서버가 처음 켜질 때 **방화벽 허용** 창이 뜰 수 있습니다. 테스트만 할 거면 취소해도 되고,
> 콘솔 모드에서 다른 기기로 접속하려면 허용해야 합니다.

### Linux
```bash
bash install_linux.sh        # 파이썬이 없으면 설치(sudo)하고, 서버를 받습니다
./run_linux.sh               # 메뉴 실행
```

### 업데이트
마인크래프트가 업데이트되면 메뉴의 **6. 서버 설치 / 업데이트** 를 누르면 최신 서버로 바뀝니다.

## 2. 사용법

**`2_run_windows.bat`** 을 더블클릭하거나, **월드 파일(.mcworld)이나 월드 폴더를 이 파일 위로 끌어다 놓으면** 메뉴가 뜹니다.
(Linux: `./run_linux.sh`)

```
 1. 월드 테스트 — 열리는지, 팩·스크립트 오류, 1분 돌린 뒤 블록 변화
 2. 시나리오로 테스트 — 명령 파일을 차례로 실행하고 결과 확인
 3. 콘솔 — 서버를 켜고 직접 명령 입력 (내 게임으로 접속도 가능)
 4. 월드 정보 보기
 5. 두 월드 비교
 6. 서버 설치 / 업데이트
 7. 다른 월드 고르기
 0. 끝내기
```

월드를 물어보면 **파일을 창 안으로 끌어다 놓고 Enter** 를 누르면 됩니다.

넣을 수 있는 것:
- `.mcworld` 파일 (게임에서 **월드 설정 → 내보내기** 로 만든 파일)
- 월드 폴더 (`level.dat` 과 `db` 폴더가 들어 있는 폴더). Windows 마인크래프트의 월드 폴더는 보통
  `%APPDATA%\Minecraft Bedrock\Users\(숫자)\games\com.mojang\minecraftWorlds\` 안에 있습니다
  (예전 버전은 `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\`).
  폴더 이름이 알아보기 어려우면 게임에서 내보낸 `.mcworld` 를 쓰는 게 편합니다.
- 서버의 `worlds\월드이름` 폴더

### 1번: 월드 테스트
아무 준비 없이 월드만 넣으면 됩니다. 서버가 월드를 열고, 월드 전체를 **실행 범위(tickingarea)** 로 켜서 정해진 시간만큼 돌린 뒤 저장된 결과를 원본과 비교합니다.
- 청크가 많으면 10곳씩 나눠서 여러 회차로 돌립니다 (기본 최대 3회차 = 청크 약 3000개, 스폰에서 가까운 곳부터).
- 걸리는 시간: 보통 1~3분.

### 2번: 시나리오 테스트
명령어를 적은 텍스트 파일(시나리오)을 차례로 실행하고, 결과가 맞는지 **통과/실패** 로 알려 줍니다.
`scenarios` 폴더에 예시가 있습니다.
- `template.txt`: 작성법 설명 + 아무 월드에서나 돌아가는 예시
- `rpg_world_example.txt`: RPG 월드(RPGWorld.mcworld)용 실제 검사 예시

시나리오 규칙:

| 줄 | 뜻 |
|---|---|
| `time set day` | 그냥 실행하고 응답만 기록 (앞의 `/` 는 있어도 없어도 됨) |
| `대기 10` | 10초 기다림 |
| `확인 testforblock 0 64 0 stone` | 명령이 **성공해야** 통과 |
| `확인 scriptevent my:diag => ok` | 응답에 **`ok` 라는 글자가 있어야** 통과 |
| `실패확인 testfor @e[type=zombie]` | 명령이 **실패해야** 통과 (= 좀비가 없어야 통과) |
| `# 메모` | 무시 (설명 쓰는 줄) |

영어로 `wait`, `check`, `checkfail` 이라고 써도 됩니다.

알아둘 점:
- 플레이어가 없어서 `@a`, `@p`, `@s` 는 대상이 없습니다. `@e[type=...]` 를 쓰세요.
- `say`, `tellraw` 의 글은 서버 기록에 안 나옵니다. 스크립트(JavaScript)는 `console.warn("...")` 으로 출력하면 기록에 나오고, `=>` 로 그 글자를 확인할 수 있습니다.
- 시나리오에 적힌 좌표(`x y z`)가 있는 곳은 첫 회차에 먼저 켜집니다. 시나리오에 `tickingarea` 명령을 직접 쓰면 자동 실행 범위는 켜지 않습니다.

### 3번: 콘솔
서버를 켜 두고 명령어를 직접 입력합니다. 응답이 바로 화면에 나옵니다. `stop` 을 입력하거나 Ctrl+C 를 누르면 끝납니다.
- 명령이 닿도록 스폰 근처부터 실행 범위를 켜 둡니다 (끝낼 때 지웁니다).
- **내 마인크래프트로 접속**: 플레이 → 서버 → 서버 추가 → 주소는 화면에 나온 IP(다른 기기) 또는 `127.0.0.1`(같은 PC), 포트 `19132`.
  접속한 뒤 콘솔에 `op 내닉네임` 을 입력하면 게임 안에서도 명령어를 쓸 수 있습니다.
  버튼, 문, 상자, NPC 대화처럼 이 도구가 자동으로 못 하는 것을 직접 확인할 때 쓰세요.
- 끝낼 때 바뀐 월드를 `.mcworld` 로 저장할지 물어봅니다.

### 4번: 월드 정보 · 5번: 두 월드 비교
- 정보: 스폰 좌표, 게임 모드, 난이도, 월드 크기(청크 범위), 연결된 팩, 엔티티·블록 데이터 개수, 게임 규칙.
- 비교: 두 월드(예: 수정 전과 후)의 블록·엔티티 차이를 같은 형식으로 보여 줍니다.

## 3. 결과 보는 법

결과는 화면에 나오고, `results\월드이름_날짜-시간\` 폴더에도 저장됩니다.
- `report.txt`: 결과 보고서 (메모장으로 열림)
- `server.log`: 서버가 출력한 전체 기록

| 항목 | 내용 |
|---|---|
| [1] 서버 실행 | 월드를 열었는지. 실패하면 서버 기록 끝부분을 보여 줍니다. |
| [2] 팩 | 월드에 연결된 팩마다 서버가 불러왔는지. "불러오지 않음" 이면 월드 폴더 안에 팩이 없거나 버전이 안 맞는 것입니다. |
| [3] 콘텐츠 로그 | 스크립트·함수·JSON 오류와 경고. 스크립트의 `console.warn` 출력도 여기 나옵니다. |
| [4] 명령 / 확인 | 시나리오의 줄마다 서버 응답과 통과/실패. |
| [5] 블록 변화 | **주의해서 볼 변화**(물·용암 흐름, 떨어진 블록, 사라진 블록, 불, 녹은 얼음 등)와 **자연스러운 변화**(잔디→흙, 작물 성장, 서버가 자동으로 채운 연결 모양 등)를 나눠서 개수와 예시 좌표를 보여 줍니다. |
| [6] 엔티티 · 블록 데이터 | 종류별 엔티티 수 변화(전 → 후), 사라진 블록 데이터(상자 내용물·표지판 글이 지워졌을 수 있음). |

예시 (RPG 월드를 돌렸을 때):
```
  주의해서 볼 변화:
    - 사탕수수·선인장이 부서짐 (...): 총 6개
        reeds → air  6개  예) -131 65 26, -131 66 26
  자연스러운 변화 (대부분 괜찮음):
    - 위가 막혀 잔디·길·나일리엄이 흙/네더랙으로 바뀜 (자연스러운 변화): 총 1870개
    - 블록 이름이 바뀜 (...): chain → iron_chain  171개
```

## 4. 이 도구로 확인할 수 없는 것

서버에 접속한 플레이어가 없기 때문에 다음은 자동으로 시험되지 않습니다.
- 우클릭, 버튼·레버·문 누르기, 웅크리기, 아이템 사용
- 상자·엔더 상자·NPC 대화 화면, 실제 화면 모습(안개, 입자, 텍스처)
- 플레이어 주변에서만 일어나는 일 (자연 몹 스폰, 플레이어를 따라오는 몹)

이런 것은 **3번 콘솔** 로 서버를 켜고 내 게임으로 접속해서 직접 확인하세요.
또, 실행 범위 밖의 청크는 서버가 돌리지 않으므로 "변화 없음" 으로 나옵니다.

## 5. 명령줄로 쓰기 (고급)

```bash
python vmc.py test 월드.mcworld                                   # 기본 테스트 (60초)
python vmc.py test 월드.mcworld --script scenarios/내시나리오.txt --seconds 30
python vmc.py test 월드.mcworld --area spawn                      # 스폰 주변 144×144칸만
python vmc.py test 월드.mcworld --area "0,0,255,255;300,0,400,100"  # 직접 지정 (x1,z1,x2,z2)
python vmc.py test 월드.mcworld --max-rounds 5                    # 큰 월드를 더 많이 돌리기
python vmc.py console 월드.mcworld [--port 19132] [--keep]        # --keep: 지난번 콘솔 월드 이어서
python vmc.py info 월드.mcworld
python vmc.py diff 이전.mcworld 이후.mcworld
python vmc.py setup [--preview]                                   # --preview: 베타 서버
```
Windows 에서는 `python` 대신 `runtime\py.bat` 을 쓰면 휴대용 파이썬으로 실행됩니다.
`test` 는 확인이 하나라도 실패하거나 서버가 안 열리면 종료 코드 1 을 돌려줍니다 (자동화용).

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 포트가 이미 사용 중 | 같은 PC에서 다른 마인크래프트 서버가 켜져 있습니다. 끄거나 `--port 19160` 처럼 다른 번호를 쓰세요. (테스트는 기본 19142, 콘솔은 19132) |
| 파이썬/서버 내려받기 실패 | 인터넷 연결을 확인하고 설치 파일을 다시 실행하세요. 회사·학교 네트워크는 막혀 있을 수 있습니다. |
| "서버가 시작되지 않았습니다" | 화면에 나온 서버 기록 끝부분을 확인하세요. 월드가 서버보다 새 버전이면 6번으로 서버를 업데이트하세요. |
| 팩을 "불러오지 않음" | 게임에서 월드를 내보낼 때 팩이 같이 들어갔는지, 월드 폴더의 `behavior_packs` / `resource_packs` 에 팩이 있는지 확인하세요. |
| `function ...` 이 "not found" | 함수 파일에 틀린 줄이 하나라도 있으면 함수 전체가 안 불러와집니다. 보고서 [3]에 몇 번째 줄이 틀렸는지 나옵니다. |
| testforblock 이 "outside of the world" | 그 좌표가 실행 범위 밖입니다. `--area` 로 범위를 지정하거나 시나리오에 `tickingarea add ...` 를 쓰세요. |

## 7. 폴더 구성

```
virtual-minecraft/
  1_install_windows.bat   설치 (Windows)
  2_run_windows.bat       실행 메뉴 (월드를 끌어다 놓아도 됨)
  install_linux.sh        설치 (Linux)
  run_linux.sh            실행 (Linux)
  vmc.py                  도구 본체
  bedrock_db.py           월드 파일 읽기 (설치할 라이브러리 없이 동작)
  scenarios/              시나리오 예시
  runtime/                휴대용 파이썬 (설치 후 생김)
  server/                 Bedrock 전용 서버 (설치 후 생김)
  results/                테스트 결과
  work/                   .mcworld 를 풀어 둔 임시 폴더
```
지우고 싶으면 폴더를 통째로 삭제하면 끝입니다. 시스템에 남는 것이 없습니다.

Bedrock 전용 서버를 받으면 [Minecraft 최종 사용자 사용권 계약](https://www.minecraft.net/eula)과
[개인정보 처리방침](https://go.microsoft.com/fwlink/?LinkId=521839)에 동의하는 것입니다.
이 도구는 Mojang/Microsoft 의 공식 도구가 아닙니다.
